1. **Title**: Create a descriptive title using H1 (# Title)
2. **Structure**: Organize content hierarchically:

   - Use H3 (###) for subsections
   - Use bullet points (-) for lists
   - Use numbered lists (1. 2. 3.) for ordered items

3. **JSON Handling**:
   - Convert JSON objects into clear key-value pairs
   - Convert JSON arrays into bullet or numbered lists
   - Format nested structures with appropriate indentation
   - Include all important data points

4. **Readability**:
   - Use clear section headings
   - Add spacing between sections
   - Make the document easy to scan and read
   - Preserve important information from the JSON

## Output Format

Format the content as markdown with proper headings, lists, and structure. The markdown will be automatically converted to a Word document.
